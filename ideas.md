# Literal Memories Pricing Calculator — Design Brainstorm

## Context
A public-facing cost estimator for a legacy media digitization service. Clients select services
(VHS, film, cassette, photo, transcription, video/audio enhancement), enter quantities or hours,
and receive a real-time estimate. The brand evokes preservation, memory, and craftsmanship.

## Option A — "Archival Warmth" (Warm Editorial / Analog Preservation)

**Design Movement:** Editorial print design meets analog archival aesthetics — think film grain,
warm amber tones, and the tactile quality of old photo albums.

**Core Principles:**
1. Warmth over sterility — every surface feels touched by time, not generated by a machine
2. Typographic hierarchy as the primary visual structure — text carries the design
3. Restraint in color — a narrow, warm palette with one sharp accent
4. Functional clarity — the calculator is the hero; decoration serves it, not the reverse

**Color Philosophy:**
- Background: deep parchment `#F5EFE0` — aged paper, not white
- Foreground text: dark sepia `#2C1F0E`
- Primary accent: burnt amber `#C4622D` — the warmth of old film
- Surface cards: `#FDFAF4` — slightly lighter parchment
- Borders: `#D9CCBA` — subtle, warm, not harsh

**Layout Paradigm:**
- Full-width header with left-aligned brand mark and a thin horizontal rule
- Single-column main content, max-width 860px, centered
- Service sections stacked vertically with clear typographic dividers (not card grids)
- Summary panel sticky on the right at desktop widths (two-column split: 60/40)
- No sidebar nav — the page is a single scroll experience

**Signature Elements:**
1. Film-grain texture overlay on the hero header (CSS noise filter, very subtle)
2. Section dividers styled as thin horizontal rules with a small centered icon (film reel, cassette)
3. Input fields with an underline-only style (no box borders) — typewriter aesthetic

**Interaction Philosophy:**
- Price updates animate with a gentle number-count-up effect
- Tier badge changes with a soft crossfade when quantity crosses thresholds
- Hover states use a warm amber underline, not background fills

**Animation:**
- Entrance: sections fade in with a 200ms upward drift on scroll
- Number changes: count-up animation over 400ms using requestAnimationFrame
- Tier change: badge pulses once with a warm glow

**Typography System:**
- Display/headings: `Playfair Display` — serif, editorial authority
- Body/labels: `Source Serif 4` — readable, warm, slightly old-world
- Monospace numbers: `JetBrains Mono` — precise, technical contrast
- Scale: 48px hero → 28px section → 18px label → 14px caption

## Option B — "Blueprint Precision" (Technical / Industrial Minimalism)

**Design Movement:** Technical drawing meets modern SaaS — inspired by engineering blueprints,
measurement tools, and the precision of professional service pricing.

**Core Principles:**
1. Grid-first structure — everything aligns to an 8px baseline grid
2. Monochrome with one electric accent — no decorative color
3. Data density without clutter — show everything, hide nothing
4. Professional authority — this feels like a tool, not a brochure

**Color Philosophy:**
- Background: near-white `#F8F9FA`
- Surface: pure white `#FFFFFF`
- Foreground: near-black `#111827`
- Accent: electric teal `#0EA5E9`
- Muted: cool gray `#6B7280`
- Borders: `#E5E7EB`

**Layout Paradigm:**
- Fixed left sidebar (240px) with service category navigation
- Main content area scrolls independently
- Summary panel fixed at bottom of viewport — always visible
- Dense table layout for services with inline inputs

**Signature Elements:**
1. Dotted grid background on the hero section (CSS background-image: radial-gradient)
2. Service rows styled like spreadsheet rows with alternating subtle backgrounds
3. Tier indicator as a horizontal progress bar showing current volume level

**Interaction Philosophy:**
- Tab-through inputs like a real spreadsheet
- Keyboard-first design — all inputs reachable without mouse
- Instant calculation with no animation delay

**Animation:**
- Minimal — only the summary total animates on change
- Tier progress bar fills smoothly with CSS transitions
- No scroll animations — prioritize speed

**Typography System:**
- Headings: `DM Sans` — geometric, clean, modern authority
- Body: `DM Sans` — consistent, no serif mixing
- Numbers: `DM Mono` — tabular figures for alignment
- Scale: 36px hero → 20px section → 16px label → 13px table

## Option C — "Memory Lane" (Warm Modern / Nostalgic Premium) ← SELECTED

**Design Movement:** Premium memory-keeping brand — warm neutrals, serif display type,
and the feeling of a beautifully designed keepsake box. Not retro, not sterile — timeless.

**Core Principles:**
1. Warmth with modern restraint — feels personal without being sentimental
2. Generous whitespace as breathing room — the calculator never feels crowded
3. Layered depth — cards, shadows, and subtle gradients create dimensionality
4. Clarity of purpose — every element either informs or enables action

**Color Philosophy:**
- Background: warm off-white `oklch(0.98 0.008 75)` — cream, not clinical white
- Card surfaces: pure white with warm shadow
- Primary: deep forest green `oklch(0.35 0.09 155)` — trust, preservation, nature
- Accent: warm gold `oklch(0.78 0.12 85)` — memory, warmth, premium
- Text: warm charcoal `oklch(0.22 0.015 65)`
- Muted: warm taupe `oklch(0.55 0.02 75)`

**Layout Paradigm:**
- Asymmetric two-column layout at desktop: calculator (65%) + sticky summary (35%)
- Hero section with brand statement left-aligned, full-width with subtle gradient
- Service categories as collapsible accordion sections with smooth expand
- Mobile: single column, summary floats as a bottom drawer

**Signature Elements:**
1. Warm gradient hero with a subtle film-strip or waveform motif (CSS only)
2. Service category headers with a small icon and a warm left border accent
3. Pricing tier indicator as a visual "milestone" bar with labeled stops

**Interaction Philosophy:**
- Accordion sections expand smoothly — clients explore at their own pace
- Quantity inputs have +/- stepper buttons for touch-friendly use
- Summary updates in real time with a gentle fade transition on price change

**Animation:**
- Hero: subtle parallax drift on scroll (5% movement)
- Accordion: smooth height transition with easing
- Price totals: gentle fade+scale on value change (not count-up — too distracting)
- Tier badge: smooth color transition when threshold is crossed

**Typography System:**
- Display: `Cormorant Garamond` — elegant serif, evokes heritage and craftsmanship
- UI/Body: `Nunito Sans` — warm, rounded, highly readable
- Numbers: `Nunito Sans` with tabular-nums feature
- Scale: 52px hero → 24px section → 16px label → 14px caption

## Selected Approach: Option C — "Memory Lane"

Rationale: Literal Memories is a service built around preserving precious family memories.
The design should feel trustworthy, warm, and premium — not cold or technical. The forest green
and warm gold palette communicates preservation and value without being garish. The asymmetric
two-column layout with a sticky summary mirrors the spreadsheet's dual-panel structure while
feeling far more approachable for non-technical clients.
